## 安裝方式

1. 在下方「Assets」點 `TWStockAnalytics-Setup-版本號.zip` 下載（比直接下載 .exe 快很多；.exe 也可以，內容一樣）
2. 在下載的 zip 上按右鍵 →「解壓縮全部」，雙擊裡面的 `.exe`。如果出現藍色的「**Windows 已保護您的電腦**」視窗：
   點「**其他資訊**」→「**仍要執行**」（安裝程式沒有付費數位簽章，所以 Windows 會先提醒）
3. 一路按「下一步」完成安裝，勾選「立即開啟台股分析」
4. 第一次開啟會進到「**開始使用**」頁，照著四個步驟設定即可

**已經安裝過舊版？** 程式左下角出現「有新版本」時按「下載並安裝更新」就好，也可以直接執行新版安裝程式。資料與持股紀錄都會保留。
